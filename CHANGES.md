## 0.1.0

Initial release: an OCaml port of @faker-js/faker 10.6.0.

- All 26 faker-js modules, each exposed as `Faker.<Module>`.
- All 77 faker-js locales, as `Faker.Locales.<Code>`. A program links only the locales it
  references, and `Faker.All_locales` links all of them.
- Seed-for-seed output parity with faker-js 10.6.0, checked by `dune test` against fixtures
  generated by running faker-js itself.
- `Faker.Number.big_int` with arbitrary precision via `Faker.Bigint`.
- Depends only on the OCaml stdlib and `unix`.
